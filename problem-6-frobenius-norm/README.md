# Frobenius Norm

Intermediate | problemset | maths-stats-for-ml | linear-algebra

Compute the Frobenius norm of a matrix: the square root of the sum of the squares of all its entries.

Implement `solve(A)`.

**Returns.** Return a float.

### Examples

**Example 1**

Input:

```python
solve([[3.0, 4.0]])
```

Output:

```text
5.0
```

**Example 2**

Input:

```python
solve([[1.0, 2.0], [2.0, 4.0]])
```

Output:

```text
5.0
```
