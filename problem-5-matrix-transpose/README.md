# Matrix Transpose

Intermediate | problemset | maths-stats-for-ml | linear-algebra

Return the transpose of a rectangular matrix, swapping its rows and columns.

Implement `solve(A)`.

**Returns.** Return a NumPy array of shape $(n, m)$ for an $m\times n$ input.

### Examples

**Example 1**

Input:

```python
solve([[1, 2, 3], [4, 5, 6]])
```

Output:

```text
[[1, 4], [2, 5], [3, 6]]
```

**Example 2**

Input:

```python
solve([[7]])
```

Output:

```text
[[7]]
```
